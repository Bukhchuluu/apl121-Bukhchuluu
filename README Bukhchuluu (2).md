# bd1: Марафоны хурд ба pace

- **Сэдвийн дугаар:** 22 (Марафоны хурд)
- **Бичлэгийн холбоос:** _(энд оруулна)_

Зай (км), дуусгасан хугацаа (цаг, мин, сек)-аас **дундаж хурд (км/ц)**, **1 км-ийн pace**, **5 км тутмын хүснэгт (хугацаа, хувь)**-ийг тооцож, **3 гүйгчийг** хугацаагаар нь эрэмбэлнэ.

## Ажиллуулах

```
gcc -Wall main.c -o main
./main
```

Программ Монгол (кирилл) текст хэвлэдэг. Git Bash дээр `???` харагдвал цонхны баруун товч, `Options`, `Text`, Character set: `UTF-8` гэж тохируулна. `main.c`-г UTF-8-аар хадгалсан байх ёстой.

## 7 элемент хаана байгаа

| # | Элемент | Хаана |
|---|---|---|
| 1 | Оролт/гаралт | `scanf`, `printf` |
| 2 | Үйлдэл ба илэрхийлэл | `niit`, `hurd`, `pace` тооцоо, логик `&&`, `\|\|` |
| 3 | Нөхцөл | `else-if` шат: Элит (>= 15 км/ц), Дундаж (>= 10), Эхлэн гүйгч |
| 4 | Давталт ба хүснэгт | `for` давталт, `%-6d %2d:%02d:%02d %8.2f` (Км, Хугацаа, Хувь%) |
| 5 | Дэд алгоритм | `quest.fprg` дээр `PrintTime`, `PrintFixed2` функц (Call блок). C дээр `main` дотор |
| 6 | Эрэмбэлэлт | 3 утгыг `if` + swap-аар эрэмбэлнэ |
| 7 | Оролтын шалгалт | `do-while` (зай, хугацаа, гүйгчийн хугацаа) |

## Өөрийн тогтоосон дүрмүүд

- Зай **25-100 км** байх ёстой. Учир нь 5 км-ийн алхамтай хүснэгт дор хаяж 5 мөртэй байх ёстой.
- Массив болон функцийг хараахан үзээгүй тул гүйгчдийг `t1, t2, t3` хувьсагчаар хадгалж, `if` ба swap-аар эрэмбэлсэн. Дугаар `b1, b2, b3`-ыг хугацаатай **хамт** солино.
- Бутархайг бүхэлчлэхдээ `(int)(x + 0.5)` ашигласан, учир нь `(int)` нь тасалдаг.
- Кирилл үсэг 2 byte байдаг тул `%-6s` зэрэг баганын тэгшлэлт кирилл дээр алдагддаг. Иймд хүснэгтийн толгойг гараар зайгаар тэгшилсэн.
- Хүснэгтийн сүүлийн мөрийн `Finish` үгийг англиар үлдээсэн.

## Мэдэгдэж буй хязгаарлалт

- Тооны оронд үсэг оруулбал `scanf` уншиж чадахгүй, программ давтагдсаар байж болно. Энэ хэсгийг хараахан үзээгүй тул шийдээгүй.
- Flowgorithm дээр `Round` ажиллахгүй бол `Int(pace + 0.5)` гэж солино.
